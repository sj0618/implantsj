# 이전 코드 보관소

현재 실행은 저장소 루트의 `./run.sh`를 사용합니다.
아래 파일은 과거 실험 재현과 참조를 위해 보존합니다.

| 경로 | 내용 |
| --- | --- |
| `implantsj/` | 자체 실행 스크립트와 workflow CLI를 가진 이전 baseline |
| `finalSJ/` | 이전 baseline의 별도 버전과 실험 설정 |
| `scripts/` | 이전 `implantsj.workflow.individual` 호출 스크립트 |
| `archives/implantsj.zip` | 루트에서 옮긴 기존 배포 압축본 |

두 코드 버전은 내용이 다르므로 합치거나 삭제하지 않았습니다.
이전 스크립트는 해당 버전의 의존성과 작업 경로를 확인한 뒤 사용합니다.
