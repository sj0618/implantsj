## 5. 클래스별 정확도

백본의 `summary.json`에는 클래스별 정확도가 직접 저장되어 있지 않지만, 각 완료 모델의 `manifest_full42_test_head.npz`에 최종 학습 헤드의 테스트 분류값과 정답 라벨이 저장되어 있었다. 저장된 클래스 순서로 최댓값을 예측 라벨로 변환해 아래 식으로 다시 계산했다.

현재 완료된 백본 8개 중 기존 6개는 클래스별 정확도 집계가 끝났다. 새로 완료가 확인된 Band-ViT 부분 미세조정 2개는 테스트 산출물까지 존재하지만, 원격 계산 코드가 `logits` 키만 읽고 실제 파일의 `features` 키를 처리하지 못해 코드 수정 전 대기 상태다.

## 7. 자료 한계

- Band-ViT 부분 미세조정 2건은 학습과 테스트 집계 지표까지 완료됐지만, 클래스별 정확도 계산 코드의 입력 키 불일치 때문에 클래스별 표에서만 제외했다.
- 기존 27개 클래스 학습 모델은 신규 15개 클래스를 분류하도록 학습한 모델이 아니므로 해당 칸을 `—`로 표시했다.
- 3개 완료 모델은 `summary.json`과 저장된 테스트 로짓 사이에 2~3장 차이가 있다. 원본을 수정하지 않았으며, 전체 지표와 클래스별 지표의 출처를 분리해 기록했다.
- 일부 클래스는 테스트 표본이 2~5장뿐이어서 100% 또는 0% 같은 클래스별 정확도를 일반적인 성능으로 해석하면 안 된다.
- 학습 모델의 클래스별 표는 최종 테스트 로짓으로 계산한 정답률이며, 클래스별 F1은 별도로 저장되어 있지 않아 포함하지 않았다.
