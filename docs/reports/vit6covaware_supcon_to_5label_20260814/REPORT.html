학습 방식

  • Source classes: ADIN, BICON, DENTIUM, MIS, NORIS, OSSTEM
  • Target unseen classes: BEGO, BILIM, IMPLANCE, ITI, NUCLEOSS
  • Model: ViT-Small backbone 384-D + projection 128-D
  • Episode: 6-way, 클래스당 support 5장 + query 5장
  • Loss: SupCon + 1.0 × covariance-aware loss
  • Covariance: diagonal class variance와 pooled variance를 0.75 비율로 혼합, β=0.001
  • Log-determinant weight: 1.0 · 30 epoch · epoch당 10 episode
  • Target 데이터는 학습·checkpoint 선택에 사용하지 않음

결론

이번 구현은 제안한 구조인 ViT + SupCon + episodic prototype + diagonal covariance-aware loss를 실제 source 학습에 적용한 것이다.

Source validation 성능은 기존보다 높아졌지만 unseen target의 Mahalanobis 성능은 기존 SupCon과 사실상 비슷하거나 소폭 낮았다. 따라서 현재 설정에서는 covariance-aware loss가 embedding을 Mahalanobis 분류에 맞게 개선했다는 증거가 부족하다.

다음 개선 후보는 covariance loss 가중치·β·logdet 항을 source episode validation에서 고정적으로 비교하거나, 학습 loss와 평가 covariance를 동일한 pooled-diagonal 방식으로 맞추는 것이다.
